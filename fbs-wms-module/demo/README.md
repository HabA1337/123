# Демо-стенд контура

Статические HTML/CSS/JS, сборки нет.

Открыть у себя:

```bash
cd fbs-wms-module/demo
python3 -m http.server 8765
```

Браузер: http://127.0.0.1:8765/

ТСД с телефона: http://&lt;ip&gt;:8765/tsd.html

Или просто `index.html` двойным щелчком.
