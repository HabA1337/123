# Актуальные цифры рынка, август 2026

Проверка первой сметы 1 850 000 ₽. Источники открытые, цифры с сайтов на 21.08.2026.

## Почему первая цена вышла большой

1 850 000 ₽ — это не «сколько стоит модуль на рынке», а смета студии: **написать контур как свой продукт** (кабинет, волны, ТСД, КИЗ, мост печати, списание) за 108 человеко-дней.

На рынке Константину продают то же самое иначе:

- готовая WMS фулфилмента уже умеет ячейки, ЛК клиента, FBS, ТСД, КИЗ, стикер;
- в 1С это собирают из готового модуля WB + программы на ТСД;
- час интегратора 1 800–4 500 ₽, типовой проект WB — 80–250 тыс. ₽, не миллион.

Завышен был **объём работ** (писать всё самим), не ставка часа. 1,85 млн / 864 часа ≈ 2 100 ₽/час — даже ниже рынка. Дорого выглядело, потому что заложили три месяца разработки вместо настройки коробки.

## Путь 3. Допилить свою ВМС

Имеет смысл, только если свою систему нельзя бросить (клиенты, ячейки, биллинг уже там).

Рынок считает не «108 дней продукта», а склейку:

| Работа | Рынок | Часы при 3 000 ₽ |
|---|---|---|
| Коннектор WB: заказы, поставка, deliver, стикеры | 80–150 тыс. | 27–50 |
| Волна «одна заявка на город» + кнопка | 40–80 тыс. | 13–27 |
| Экраны ТСД: ШК → КИЗ → стикер | 80–120 тыс. | 27–40 |
| Вкладка репринта КИЗ + веб | 30–50 тыс. | 10–17 |
| Мост печати (очередь, ZPL, журнал) | 40–80 тыс. | 13–27 |
| ЛК клиента: приёмка/ячейки онлайн | 80–150 тыс. | 27–50 |
| Мониторинг % и лента ТСД | 40–70 тыс. | 13–23 |
| Автосписание остатка по продаже WB | 40–60 тыс. | 13–20 |
| Запуск на складе | 40–60 тыс. | 13–20 |
| **Итого** | **470–820 тыс.** | **156–274 ч ≈ 20–35 дней** |

Календарь при одном сильном интеграторе + частичной занятости второго: **6–8 недель**.

Фикс, который стыкуется с рынком, а не со студийным «продуктом»: **590 000 ₽**.

Сопровождение API WB у интеграторов: **25–40 тыс. ₽/мес** или 50–150 тыс. ₽/год. 90 тыс./мес из первой сметы — завышено в 2–3 раза.

## Что из ТЗ Константина коробка уже закрывает

| Требование | SkladBot / МПФИТ / Целиком | 1С + модуль WB + Allegro/DataMobile |
|---|---|---|
| Приёмка и остатки клиенту по ячейкам | да, ЛК + адресное хранение | да, если ячейки в 1С |
| FBS сам стягивает заказы | да | да |
| Одна заявка на город | обычно поставка/волна, город — настройка | поставка WB, группировка дописывается |
| Мониторинг % и лента ТСД | частично (статусы, онлайн-документ) | онлайн-контроль документа |
| Кнопка «в доставку» | да, поставка WB | да |
| ШК → КИЗ → стикер WB | да, у Целиком прямо в описании процесса | да, скан ШК печатает стикер |
| Мост ТСД–система–принтер | встроен (Целиком отдельно настраивает оборудование во входном платеже) | печать с ТСД / из 1С, отдельный мост не нужен |
| Продажа WB → минус остаток | да, общий остаток | да, обмен остатками |

Кастом оправдан, если есть жёсткое «заявка строго по городу как один документ», своя модель ячеек/биллинга или запрет сажать клиентов в чужой облачный контур.

## Как отвечать на «сколько стоит один модуль»

| Если имеют в виду | Честная цифра |

| Купить и запустить | **30–80 тыс. вход + 15–40 тыс./мес**, 2–4 недели |
| Собрать на 1С | **300–500 тыс. вход**, 4–8 недель |
